# ChatKeep

Drop a WhatsApp **Export Chat** `.txt` or zip. Get a searchable HTML archive and a CSV. Files never leave the browser.

Ask this answers: [I am about to lose again years of chat history on Whatsapp](https://www.reddit.com/r/whatsapp/comments/1vozoti/i_am_about_to_lose_again_years_of_chat_history_on/)

- No account
- No upload
- Cap: 15 MB
- Parses iOS `[date, time] Name:` and Android `date, time - Name:` exports

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

In WhatsApp: open the chat → ⋮ or contact name → Export chat.

## GTM

Reply to people who are about to wipe a phone and still have the chat only inside WhatsApp. Copy is in the page footer.
